# 분석 품질 점검 및 개선안 — 2026-11-27

현재 상태: `codex/analysis-quality`의 검토용 변경안. 프런트엔드는 정식 운영(main)에 아직 반영하지 않았다. 별도 인구 조회 함수 `sgis-context-v2`만 기존 Supabase 프로젝트에 배포했다(version 2, JWT 검증 사용). 기존 운영 조회 함수는 그대로다. 반경 인구 추정은 실제 API로 확인했지만 경쟁점 원본·실제 소비 수요 검증은 남아 있으므로 유료 분석 품질이 완성됐다고 볼 수 없다.

## 계산 원칙

- 영업 손익분기 월매출 = (월세 + 관리비 + 직원 인건비 + 기타 고정 운영비 + 별도 보험료) / (1 − 변동비율).
- 현금 손익분기 월매출 = (고정 운영비 + 대출 이자 + 원금 상환 + 사장님 생활비) / (1 − 변동비율).
- 목표 월매출 = (위 현금 지출 + 생활비 외 추가 목표 잉여금) / (1 − 변동비율).
- 하루 필요 주문 = 목표 월매출 / 월 영업일 / 부가세 제외 객단가, 올림.
- 원금 상환·사장님 인출금은 영업 비용과 구분한다. 보증금과 권리금을 월 운영비에 중복 합산하지 않는다.
- 매출·비용·객단가는 부가세 제외 기준. 세금·감가상각·시설 투자 회수는 별도이며 잉여 현금을 회계상 순이익이라고 표시하지 않는다.
- 비용 미입력과 명시적인 0을 구분한다. 누락된 비용이 있으면 계산 결과는 하한으로 표시한다.
- 매출 −20%와 변동비율 +5%p는 스트레스 가정이며, 실제 매출 예측이나 발생 확률이 아니다.
- 권리금 회수는 입력 매출에서 생활비·대출 후 잉여가 있을 때만 계산한다. 적자를 흑자로 추정하지 않는다.

## 불완전 보고서 처리

현재는 모든 신규 검토에서 실제 소비·매출과 최신 입주 근거의 교차 검증이 부족해 `scoreWithheld: true`다. 인구를 확보했다는 이유만으로 매출 가능성이나 안전 등급을 부여하지 않는다. 참고 결과를 화면에 제공하되 기존 `save_analysis_and_consume_credit` 호출 전에 반환한다. 따라서 이 브랜치를 운영에 반영하면 해당 검토는 크레딧을 차감하거나 유료 보관함에 저장하지 않는다. 기존 RPC·결제·환불·DB 스키마는 변경하지 않았다.

무료 참고 검토에 크레딧 구매를 요구하지 않도록 잔여 크레딧 확인은 완성된 유료 결과 저장 직전으로 옮겼다. 로그인은 기존 정책대로 필요하다. 정식 전환 시 마케팅의 실제 시장·CRI·가격 안내와 참고 검토 정책도 함께 맞춰야 한다.

마이페이지는 v3 보고서 형식을 읽을 수 있도록 준비했으며 기존 v2 보고서도 계속 표시한다. v3 저장 화면은 개발용 가상 데이터로만 검증했다. 실제 저장 성공을 뜻하지 않는다.

## 반경 인구 연동

- `year/data.json`에서 제공 연도를 확인한다. 연도 조회 실패 시 오래된 연도로 조용히 대체하지 않는다.
- 좌표를 EPSG:5179로 변환하고 집계구 경계와 반경 100~1000m 원의 교차 면적을 계산한다. Polygon/MultiPolygon, 내부 구멍, 중복 경계를 처리한다.
- 반경에 걸친 행정동들의 집계구 통계를 조회한다. 행정코드는 7·8자리 전체를 유지하고, 행정동 합계는 일치하는 코드의 행만 사용한다.
- 집계구 안에 인구가 균일하게 분포한다고 가정한 면적 비례 추정이다. 신규 입주·산업시설·공원·도로 단절·실제 구매력은 설명하지 못한다.
- 경계가 반경을 덮고 모든 교차 집계구의 인구가 확인될 때만 총 추정치를 표시한다. 비공개·누락은 0이 아니며, 일부만 확인되면 확인분 소계와 누락 집계구 수를 따로 표시한다.
- 완전히 포함된 집계구 합계와 조금이라도 걸친 집계구 전체 합계도 제공한다. 공간 배치에 따른 범위이며 통계적 신뢰구간이 아니다.
- 서버 비밀키는 기존 서버 설정에서만 읽는다. 새 함수는 공공 통계만 조회하며 사용자·크레딧·결제 테이블에 접근하지 않는다.

## 유료 분석 전환을 위해 남은 작업

1. **새 보고서 통합 점검**: 로그인 상태에서 새 인구 조회 함수 호출과 오류 복구, 새 인구 카드의 모바일 배치, 외부 CSV와 동시 조회 시간을 확인한다. 검토용 함수만 배포됐으며 main 전환은 아직 하지 않았다.
2. **반경 수요 보강**: 집계구 면적 배분 추정에 신규 아파트 입주/미입주 및 도보 단절을 보완한다. 2024년 통계·2025년 경계의 시점 차이를 사례별로 검토한다. 실측 인구로 부르거나 행정동 전체 숫자에 반경 배율을 곱하지 않는다.
3. **CSV 원본과 최신성 검증**: 외부 CSV 저장소 연결, 지역별 원본 기준일·버전 메타데이터 추가. 세 지역 이상(구도심, 신축 주거지, 행정 경계)에서 점포 원장과 결과를 대조하고 최근 개·폐업 표본 확인. 다중 지역 로드의 실제 모바일 메모리·다운로드 성능도 검증한다.
4. **실제 매출 가능성 근거**: 지역·업종·기간별 카드 소비 또는 가맹점/상가 POS 자료가 있어야 목표 매출 달성 가능성을 논의할 수 있다. 현재 비용 역산은 매출 예측이 아니다.
5. **의사결정 검증**: 근거의 시점·범위·누락 비율과 낮음/기준/높음 가정을 보여주고, 사람이 검토한 실제 후보지 사례로 결론의 적합성을 평가한다. 검증되지 않은 성공 확률이나 안전 등급을 다시 붙이지 않는다.
